# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Changed
- Redesigned every screen in a warm dark look: gold accent, Plus Jakarta Sans,
  pill buttons and a floating navigation bar. Layouts are a ranked list with a
  confirm bar, room selection shows the picked room with a tile grid, and the
  phone 3D viewer has a turn slider with Pieces and Room details tabs.
- README screenshots now show the redesigned screens.

### Added
- `tool/readme_screenshots_test.dart` regenerates the README screenshots.
- README screenshots, MIT license, contributing guide, issue and pull request
  templates, and a continuous integration workflow.

## [1.0.0]

### Added
- Floor-plan upload with preview, room detection and layout recommendations.
- Interactive 3D room viewer with PNG and `.glb` export.
- Email and username sign-in, profile, themes and administration tools.
